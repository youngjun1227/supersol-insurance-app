# 아이콘 매핑표 — Phosphor Icons (MIT)

> 최종 UI(D-1)에서 쓰는 아이콘 **43개** (41 + `선물` 2026-08-23 + `사람` 2026-08-25). Figma 컴포넌트 세트 **`아이콘 (Phosphor)` = `278:110`** (페이지 `🧩 컴포넌트 · 토큰` / 섹션 `278:111` 🔒).
> 선택 근거·한계는 `03_final-ui/디자인.md` §7. 라이선스: Phosphor Icons, MIT (상업적 사용·수정 허용, 고지 불필요하나 발표 자료 크레딧에 한 줄 넣는 것을 권장).

## 쓰는 법 (Figma 초보용)

1. 화면에서 **[아이콘 플레이스홀더]** 인스턴스를 클릭
2. 우측 패널 맨 위의 컴포넌트 이름을 눌러 **`아이콘 (Phosphor)`로 교체(Swap instance)**
3. 바로 아래 **`Name` 드롭다운**에서 아래 표의 이름을 고름

- 색은 **색상 변수에 바인딩**되어 있다 → 라인 36개 = `text/secondary`, `탭-*` 5개 = `text/disabled`. **SOL 모드로 바꾸면 자동으로 따라온다.** 다른 색이 필요하면 인스턴스에서 fill 변수만 바꾼다(직접 hex 입력 ❌).
- 크기는 **24 기준**. 32·44로 키울 때는 인스턴스를 그냥 리사이즈하면 된다 — 채움 패스라 획 두께가 비율대로 커진다.
- **표에 없는 아이콘이 필요하면 영준에게 요청.** 다른 세트에서 임의로 가져오면 결이 어긋난다(§7 실측 근거).
