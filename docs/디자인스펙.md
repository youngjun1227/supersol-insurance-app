# 슈퍼SOL 보험 탭 — 프론트엔드 디자인 스펙

> **React 구현(1차: 8/25~31) 기준 문서.** Figma `최종 UI 디자인`(`5:4`) 화면을 그대로 코드로 옮길 때 이 문서대로 한다.
> 값의 출처: `00_reference/design-tokens/tokens.md`(캡처 픽셀 실측) · `03_final-ui/디자인.md`(확정 규칙, §번호는 그 문서 기준).
> 이 문서는 개발 레포로 복사해 간다. **디자인이 바뀌면 원본(디자인.md)을 고치고 여기에 반영한다** — 여기서만 고치지 않는다.

## 0. 전제

| 항목 | 값 |
|---|---|
| 기준 뷰포트 | **393 × 852** (iPhone 14/15 Pro). 1pt = 1px(CSS px) |
| 레이아웃 | 모바일 고정. `max-width: 393px` 중앙 정렬, 밖은 회색 여백 (데스크톱에서 열어도 폰 프레임처럼) |

| 홈 화면 추가 | `manifest.json` + `apple-mobile-web-app-capable` — 주소창 없는 전체화면. 앱 아이콘: `슈퍼쏠앱아이콘_투명.png` |

## 1. 색 토큰 (CSS 변수)

  /* Text */
  --text-primary:       #101828;  /* 제목·선택 탭·상품명 */
  --text-secondary:     #344054;  /* 카드 제목·리스트 항목·본문 */
  --text-tertiary:      #475467;  /* 비선택 탭·키-값 라벨 */
  --text-caption:       #667085;  /* 부제·설명·푸터·비선택 상단탭 */
  --text-disabled:      #818DA2;  /* 탭바 비선택·chevron·비활성 */
  --text-black:         #000000;  /* 페이지 큰 제목("금융") */
  --text-link:          #005DF9;

## 4. 공통 레이아웃 셸 (`<AppShell>`)

모든 화면 = **[헤더] + [스크롤 본문] + [탭바 또는 하단 CTA]** 3단.

```
┌─────────────────────────┐
│ Header (h56, sticky)     │ ← 제목형: h1 22 Bold #000 / 서브형: ← 뒤로 + 20 Bold
│ (상단 탭 행 h46, 옵션)     │ ← S1·S2 계열만
├─────────────────────────┤
│ 본문 (overflow-y: auto)  │ ← 배경은 §1 배경 규칙
│                          │
├─────────────────────────┤
│ TabBar 363×62 플로팅 pill │ ← position: fixed, bottom: 12+safe-area, 중앙
│  또는 BottomCTA h102 흰 배경│ ← 화면당 둘 중 하나만
└─────────────────────────┘
```

- **탭바**: 흰 배경 + `--shadow-float`. 탭 5개(홈·금융·상품·혜택·주식). 선택 = **채움 아이콘 22 + 라벨 12/500, 색만 `--primary`** / 비선택 = 같은 아이콘 `--text-disabled`. **선택 원 같은 건 없다** (8/23 정정).
- **하단 CTA**: `position: fixed` 흰 배경 h102, 버튼 h56 r16 폭 353.
- 본문 스크롤 시 헤더는 sticky, 탭바·CTA는 fixed — Figma 프로토타입의 "고정 요소"와 동일 동작.

### 화면 전환

Figma 프로토타입에 걸어둔 규칙 그대로:
- 화면 이동 = 오른쪽에서 밀려 들어옴 (PUSH LEFT 0.3s)
- 시트·모달 = 아래에서 올라옴 (0.35s)
