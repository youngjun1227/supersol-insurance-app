## 1. 계측 로그 백업 절차

로그는 참가자 폰 브라우저의 **localStorage 한 곳**에만 쌓인다. 브라우저 데이터가
날아가면(시크릿 모드 종료·저장공간 정리) 그 세션 로그는 유실이다.

- **참가자 1명 끝날 때마다 `/export` 에서 내보내기** — 진행자 체크리스트에 명문화
- 시크릿 모드에서는 계측이 아예 안 쌓인다 — `/export` 상단에 경고 배너가 뜨면
  다른 브라우저로 바꾼다 (#99)

## 2. 접속 정보

| | |
|---|---|
| 참가자 링크 | https://supersol-insurance-app.vercel.app |
| 진행자 화면 | 홈 헤더 **"김신한님" 5번 연속 탭** → `/demo` |
| 계측 내보내기 | `/demo` 에서 이동, 또는 `/export` 직접 |

참가자에게는 **맨 위 링크만** 준다. 진행자 화면 주소는 알려주지 않는다.

      — 앱을 켜면 첫 화면이 상황 선택이다. 고르고 나면 홈으로 들어간다
      — 참가자는 이 화면을 보지 않는다 (#130)

## 4. 리허설에서 볼 것 (체크 항목 밖)

- 참가자가 과제를 읽고 **어디를 먼저 누르는지** — 라벨이 오해를 부르는지
- 한 과제에 걸리는 대략의 시간 — 4과제 + 평가지가 한 세션에 들어가는지
- 진행자 조작이 참가자 시야에 들어가는지 (숨은 입구를 쓰는 이유)
