# 참고자료 — 남이 만든 것

우리가 작성하지 않은 입력물. **여기 있는 걸 고치지 않는다** — 원본 그대로 둔다.

## 넣을 것

- **과제 브리프** — 신한라이프 일경험 원본 (지표 §4 근거)
- **기존 슈퍼쏠 보험 탭 캡처** — AS-IS 화면. 비교 대상이라 테스트 시점 버전으로 박제한다
  ⚠️ 실제 앱은 업데이트된다. **9/11 당일 버전을 캡처해 두지 않으면** 나중에
  "그때 그 화면이 맞나" 를 증명할 수 없다
- **척도 원본** — SUS 등 표준 설문을 쓴다면 출처·원문
- 선행 연구·아티클 — 인용할 것만

## 넣지 말 것

- 우리가 만든 평가지·스크립트 → `../평가도구/`
- 참가자가 채운 것 → `../응답원본/`
