# 연구 참여 동의서

> 인쇄해서 세션 시작 전에 받는다. **녹음·촬영을 하면 필수**다.
> 녹음 안 하면 구두 고지로 충분하지만, 서명본이 있으면 발표에서 축어 인용을 쓸 때 근거가 된다.

---

## 보험 앱 화면 사용성 평가 — 참여 동의서

**조사 목적**
보험 앱 화면 두 가지를 직접 써보시고, 어떤 점이 편하고 어떤 점이 불편했는지
듣기 위한 조사입니다. 학습 과제의 일부이며 상업적 목적이 없습니다.

**진행 방식**
- 약 20~30분 동안 앱 화면에서 몇 가지 과제를 해보시고, 질문에 답해 주십니다
- **정답이 있는 시험이 아닙니다.** 잘 안 되는 부분이 있어도 괜찮습니다
- 화면에 나오는 보험 상품·금액·이름은 **전부 시연용 가상값**입니다. 실제 가입이나
  금융 거래는 일어나지 않습니다

**기록되는 것**
- 답변 내용 (설문 입력 및 진행자 메모)
- 앱에서 어느 버튼을 눌렀는지 (앱 안의 기록)
- ☐ 음성 녹음 (동의하신 경우에만)

**기록의 사용**
- 참여자는 이름 대신 **번호(P1, P2…)로만** 기록됩니다
- 이름·연락처는 어떤 자료에도 남지 않습니다
- 답변 일부가 발표 자료에 **인용될 수 있으며**, 이때도 번호로만 표기됩니다
- 원본 기록은 조사팀 내부에만 보관하며 외부에 공개하지 않습니다

**참여자의 권리**
- 언제든 이유 없이 중단하실 수 있습니다
- 답하고 싶지 않은 질문은 건너뛰실 수 있습니다
- 중단하셔도 불이익이 없습니다
