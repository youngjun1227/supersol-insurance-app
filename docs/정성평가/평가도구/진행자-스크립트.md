# 진행자 스크립트 — 9/11 정성평가

> **읽는 그대로 말한다.** 어미 하나가 답을 기울인다 — 이 문서가 있는 이유다.
> 과업 지시문은 [`평가지.md`](평가지.md) 와 한 글자까지 같다. 여기서 바꾸지 않는다.
> 판정 기준은 [`채점기준.md`](채점기준.md). 근거는 [`../진행계획.md`](../진행계획.md) §4.

**적어도 되는 것 / 안 되는 것**

| ⭕ 읽는다 | ❌ 절대 안 한다 |
|---|---|
| 「」 안의 문장 | "이게 더 편하죠?" 처럼 답이 든 질문 |
| 참가자가 막혔을 때 정해진 한 문장 | 힌트 · 화면 가리키기 · "저기요" |
| "구체적으로 어느 부분이요?" | "저희가 만든 건데요" — 만든 사람임을 밝히기 |

## 0. 세션 전 (참가자 앉기 전, 5분)

- [ ] 설문 앱 열기 — `survey-app/dist/index.html` 더블클릭 → **P번호 · 보유/미보유 · 순서** 입력
- [ ] 참가자 폰: 앱 열어 **배정된 상황 카드 미리 눌러 두기** (참가자는 진입 화면을 안 본다)
- [ ] 순서 확인 — **P1·P3·P5·P7 = 기존 먼저 / P2·P4·P6·P8 = 우리 먼저**
- [ ] 녹음할 거면 동의서 인쇄본 준비
- [ ] 시크릿 모드 아님 확인 (계측이 안 쌓인다)

## 1. 도입 (0~3분)

「안녕하세요, 시간 내주셔서 감사합니다. 오늘은 보험 앱 화면 두 가지를 써보시고
어떠셨는지 들려주시는 자리예요. 20분에서 30분 정도 걸립니다.」

「**정답이 있는 시험이 아니에요.** 화면이 헷갈리거나 못 찾겠으면 그게 저희한테
제일 중요한 정보예요. 잘 안 되는 게 있으면 그대로 두셔도 됩니다.」

「중간에 제가 "지금 무슨 생각 하세요?" 라고 물을 수 있어요. 떠오르는 대로
말씀해 주시면 됩니다.」

*(녹음한다면)* 「기록을 위해 녹음을 하려고 하는데 괜찮으실까요? 이름은 남지 않고
P번호로만 정리돼요.」 → **동의서 서명** → 설문 앱 "녹음 동의" 체크

⚠️ **"저희가 만들었다"는 말은 끝까지 하지 않는다.** 두 앱을 "첫 번째 화면" ·
"두 번째 화면"으로만 부른다. 어느 쪽이 우리 것인지 알면 좋게 답한다.

### 도입 3문항 — 앱 보여주기 **전에**

설문 앱 D1~D3 를 참가자가 직접 입력하거나, 말로 답하면 진행자가 친다.

「먼저 보험에 대해 세 가지만 여쭤볼게요. 앱은 그 다음에 보여드릴게요.」

- **D1** 「마지막으로 보험금을 청구하신 게 언제인가요? 그때 어떻게 하셨는지
  순서대로 말씀해 주세요. 안 하셨다면 왜 안 하셨는지도 좋아요.」
- **D2** 「이번 달 보험료가 얼마인지 알고 계세요? 마지막으로 확인한 게 언제,
  어디서였나요?」
  *(미보유자)* 「부모님이 들어주신 보험이 있는지 아세요?」
- **D3** 「내 보험이 충분한지 궁금했던 적이 있나요? 그때 무엇을 하셨어요?
  아무것도 안 하셨다면 그것도 답이에요.」

⚠️ 여기서 "저희 앱은 그걸 해결하려고…" 같은 말 금지. **그냥 듣는다.**

## 2. 과업 — 첫 번째 앱 (3~12분)

「이제 첫 번째 화면이에요. 제가 할 일을 말씀드리면 평소 하시던 대로 해보시면 돼요.
저는 옆에서 보기만 할게요.」

### 과업 지시문 (양쪽 앱 **동일**)

| 순서 | 과제 | 읽는 문장 |
|---|---|---|
| 1 | `premium` 보유자 | 「이번 달 내는 보험료가 얼마인지 확인해주세요.」 |
| 1 | `premium` 미보유자 | 「보험에 가입하면 이 앱에서 뭘 할 수 있는지 확인해주세요.」 |
| 2 | `claim` | 「보험금을 청구하려고 합니다. 청구를 시작하는 화면까지 가주세요.」 |
| 2-1 | 팝업 *(우리 앱만, 과제 끝난 뒤)* | 진행자가 `/home?popup=claim` 열고 → 「이런 안내가 떴다고 해볼게요.」 |
| 3 | `menu` *(보유자만)* | 「보험 관련 기능 중에서 보험료 납입 화면을 찾아주세요.」 |
| 4 | `diagnosis` | 「내 보험 보장이 어떤 상태인지 확인해주세요.」 |
| 5 | `product` | 「치아를 보장하는 보험을 찾아서 하나를 열어봐 주세요.」 |

⚠️ **양쪽 다 홈에서 시작한다.** 우리 앱만 팝업 뜬 채로 시작하면 우리만 목적지
한 걸음 앞에서 출발하는 것이라 성공률이 오염된다. 팝업은 과제가 끝난 **뒤** 보여준다.

⚠️ **기존 앱에는 `diagnosis` 대응 화면이 없다.** 그래도 같은 문장을 읽는다.
참가자가 뭘 눌러보다 포기하는지가 데이터다. 진행자 기록란에 **"N/A + 탐색 경로"**.

### 과제 중 진행자가 하는 일

**본다. 적는다. 말하지 않는다.**

- 기록란에 **첫 탭한 곳**을 적는다 — 라벨이 오해를 부르는지 여기서 드러난다
- 시간을 잰다 — **3분** 넘으면 「여기까지 해볼게요」 하고 실패로 기록

**참가자가 막혔을 때** — 3초 세고, 이 문장만:
「지금 무슨 생각 하고 계세요?」

그래도 막히면: 「무엇을 찾고 계세요?」
그래도 막히면 → 실패로 기록하고 다음 과제. **힌트를 준 순간 그 과제는 실패다.**

**참가자가 물어볼 때**
- 「이거 눌러도 돼요?」 → 「평소 하시던 대로 해보세요.」
- 「이게 맞아요?」 → 「어떻게 생각하세요?」 (되돌려준다)
- 「카카오톡으로 오나요?」 → 「그 부분은 이번에 준비되지 않았어요.」 **여기서 끝.** 설명 금지

### 과제 직후 문항

각 과제 끝나면 설문 앱 해당 문항을 참가자가 입력한다. 진행자는 **노란 칸(판정)** 만 친다.

**진행자 판정 문항 — 말로 물어서 채점**

- **Q9** *(보유자, 화면 덮고)* 「두 번째 화면의 보험 메뉴가 몇 개 묶음으로 나뉘어
  있었는지 기억나세요?」 → 3분류 인지 □함 □못 함
- **Q16** *(화면 덮고, 실제 뜬 값으로)* 「방금 화면에 보장 에너지 **30%**(미보유: 0%)
  라고 나왔는데요, 이 숫자가 무엇을 기준으로 나온 거라고 생각하세요?」
  → 정답 = "정해진 항목 중 내 보험이 채운 비율" 계열
  ⚠️ **문구를 대신 읽어주지 않는다.** 읽어주면 그 자리에서 이해하고 답해서 측정이 무의미해진다
- **Q17** *(briefing 도달자만, 차트 보며)* 「이 그림에서 내 보장이 가장 부족한 영역은
  어디예요?」 → □정답 □오답 □답 못 함
  *(미보유자)* 「이 그림이 무엇을 보여준다고 생각하세요?」 → 주관식

## 3. 과업 — 두 번째 앱 (12~21분)

「이번엔 두 번째 화면이에요. 아까랑 **같은 걸** 해보실 거예요.」

→ §2 과업 지시문을 **한 글자도 바꾸지 않고** 다시 읽는다.

⚠️ 두 번째 앱이 우리 것이어도 「이건 저희가…」 금지. 참가자가 「이거 다른 회사예요?」
물으면 → 「어떻게 느끼셨어요?」 로 되돌린다.

## 4. 비교 · 반응 (21~27분)

설문 앱 Q22~Q29 를 참가자가 직접 입력한다. 진행자는 **주관식에 파고드는 역할**만.

**칭찬이 나오면** — 거기서 멈추지 않는다:
「구체적으로 어느 부분이요?」
「그럼 지금 쓰시는 앱 대신 이걸 쓰실 것 같으세요? 왜요?」

**"좋네요" / "괜찮네요"** 는 데이터가 아니다. 위 두 문장을 붙여야 기록이 된다.

**Q27·Q28 (반증 문항)** — 반드시 두 방향 다 묻는다:
「두 번째 화면에서 불편하거나 이상했던 건요?」
「반대로 첫 번째 화면이 더 낫다고 느낀 부분은요?」

⚠️ 8명 전원이 좋다고만 하면 **결과가 아니라 진행이 잘못됐다는 신호**다.
불리한 답이 나오는 것이 이 조사가 정직했다는 증거다.

## 5. 마무리 (27~30분)

「마지막으로, 오늘 보신 것 중에 이해가 안 되거나 낯설었던 표현이 있었나요?」 *(Q29)*

「감사합니다. 말씀해 주신 게 정말 도움이 됐어요.」

### 세션 후 (참가자 나간 뒤, 반드시)

- [ ] 설문 앱 **제출** → **CSV 내려받기** → `응답원본/P{n}.csv` 로 저장
- [ ] 참가자 폰 `/export` → **JSON 내려받기** → `응답원본/P{n}-계측.json`
  ⚠️ **참가자 1명마다 한다.** localStorage 한 곳이라 브라우저 데이터 날아가면 유실
- [ ] `/export` → "다음 참가자 (세션 새로 시작)"
- [ ] 관찰 메모에서 **기억 안 나기 전에** 인상 깊었던 말 1~2개 적기
- [ ] 다음 참가자 상황 카드 미리 눌러 두기
