# 응답원본 — 참가자가 채운 것

## 🚫 이 폴더의 내용물은 커밋되지 않는다

**이 저장소는 public 이다.** 참가자 실명·음성·필적이 한 번 올라가면 `git rm` 을 해도
히스토리에 남아 되돌릴 수 없다. `.gitignore` 가 이 폴더를 막고 있고,
추적되는 건 **이 README 뿐**이다.

## 여기 두는 것 (로컬에만)

- 응답지 스캔·사진, 입력본(엑셀·시트)
- 녹음·화면 녹화
- 진행자 관찰 메모 원본
- `/export` 에서 내려받은 계측 CSV·JSON

## 보관

- **로컬 + 팀 드라이브 2벌.** 저장소는 보관 장소가 아니다
- 참가자 1명 끝날 때마다 `/export` 내보내기 — localStorage 한 곳에만 쌓여서
  브라우저 데이터가 날아가면 유실이다 ([리허설 체크리스트](../../운영/9-11-리허설-체크리스트.md) §1)
- 파일명에 실명 금지. `P1-premium.jpg` 처럼 참가자 번호로

## 저장소로 나가는 것

집계한 수치만 `../분석결과/` 로. 원본은 여기서 나가지 않는다.

## 동의

녹음·촬영을 한다면 **동의서가 선행**이다 (`../평가도구/동의서.md` — 아직 미작성).
