# 분석결과 — 우리가 뽑은 것

`../응답원본/` 을 집계한 결과. **저장소에 올리는 건 여기까지다.**

## 넣을 것

- `집계표.md` (또는 .csv) — 과제별 성공률, 평가지 문항별 평균
- 발표용 그래프 — 9/20 발표 §7 "검증 결과" 120초에 쓸 것
- 관찰 메모 요약 — "8명 중 5명이 보험금 청구를 먼저 눌렀다" 류

## 규칙

- **참가자는 `P1`·`P2` 로만.** 실명·연락처·소속 금지 (public 저장소)
- 원본 응답을 그대로 옮기지 않는다 — 집계된 수치와 익명 인용만
- 인용은 참가자가 특정되지 않는 선까지만

## 수치를 쓸 때

- **클릭 수·시간은 비교에 쓰지 않는다** (변경로그 §"지표 위상 재정의")
- 표본이 작다 — "평균 4.2 vs 5.1" 같은 소수점 비교는 참가자 2명만 바뀌어도 뒤집힌다.
  **"기존 앱에서 3명이 못 찾았는데 우리 것에서는 전원이 찾았다"** 처럼
  세는 방식으로 말하는 게 정직하고 강하다
- n 을 반드시 같이 적는다. "80%" 만 쓰면 5명 중 4명인 걸 숨기게 된다
