### 2. S3 보장 진단 결과 (S3-C) — 요약 히어로 카드 + 티어 접기 ⭐ 구조 변경

**요약 카드** (기존 요약 블록 + 하단 "내 보험이 채우는 에너지" 섹션 통합):
```
┌─ 틴트 카드 #F4F6FE r16 p20(상24 하16) gap12, 모두 중앙 정렬 ─┐
│            [배터리 30% 64×85]                              │
│            보장 에너지 30% (18/700)                         │
│   10개 항목 중 3개를 내 보험이 채우고 있어요 (14/400)           │
│   20대 기준 우선순위로 정리했어요 (13 caption)                 │
│ ── 1px #E4E7EB ─────────────────────────────────────────  │
│ 신한통합건강보험 원(ONE)Core (14/500) [부모님 가입 뱃지]        │
│ 암 진단·입원 에너지를 채우고 있어요 (13 caption)                │
│ ── 1px ────────────────────────────────────────────────── │
│ 신한SOL대중교통보험 mini                                     │
│ 후유장해 에너지를 조금 채우고 있어요                            │

```
- 내 보험 행에 **박스 없음** — 틴트 위 직접 배치 + 구분선 (흰 인셋 박스는 시도 후 폐기)

**티어 접기** — 티어당 항목 **최대 3개** 표시, 초과분은 접힘:
- 현재 데이터로는 "여유 있을 때 봐도 돼요"(6개)만 해당: 수술·치과치료·심혈관질환진단 표시, 뇌혈관·치매·후유장해 접힘
- 토글 행: `항목 3개 더 보기 ∨` — **배경 없음**, 14/500 `#667085`, chevron 회전, 상하 패딩 6. 버튼처럼 크게 만들지 말 것 (한 번 크게 갔다가 축소함)
- 펼치면 제자리 확장(React: height 애니메이션), 토글이 `접기 ∧`로. **접힘이 기본 상태**
- Figma: 접힘 `485:2920` / 펼침 `S3-C-1` `604:8662`

**티어 전체 매핑 (2026-08-26 확정 — 이걸로 데이터 모델에 `tier` 필드 추가)**:

티어는 기존 `group`(치료비/큰 병/노후·간병/만일)과 **별개 축**이다 — 기준은 "20대 중요도 × 충족 여부"이지 보장 유무가 아니다.

| tier 키 (제안) | 이름 | 항목 (표시 순서 고정) | 카운트 라벨 |
|---|---|---|---|
| `now` | 지금 채우면 좋아요 | 실손의료비 · 입원 — 둘 다 "먼저 볼 항목" 뱃지 | "20대 우선 · 2개 항목" |
| `later` | 여유 있을 때 봐도 돼요 | 수술 · 치과치료 · 심혈관질환진단 · 뇌혈관질환진단 · 치매진단 · 후유장해 | "6개 항목" |
| `covered` | 이미 준비돼 있어요 | 암 진단 | "1개 항목" |
| `notyet` | 지금은 서두르지 않아도 돼요 | 사망 | "1개 항목" |

- **후유장해가 `later`인 것은 의도** — 보유(1,000만) 중이지만 또래 수준(3,000만) 미달이라 `covered` 자격이 없고, 20대 중요도가 낮아 `now`도 아니다. 반례로 입원은 일부 보유인데도 중요도가 높아 `now`. `covered`는 "또래 평균 도달"만 들어간다.
- 접기 규칙: 티어당 앞 3개 표시, 나머지 접힘 — 별도 선정 기준 없음, **티어 내 고정 순서** 필드로 구현
- 카운트 라벨은 티어별 문자열이 다름(`now`만 "20대 우선 ·" 접두) — 데이터에 라벨 통째로 두는 게 안전
- 원본 기록: 디자인 레포 `02_to-be/mock-data.md` §2-3
- 항목 배터리 단계 규칙: **없음 = 0 / 일부 보유 = 30 / 또래 평균 도달 = 100** (60은 현재 미사용 — 실손·수술·치과·심혈관·뇌혈관·치매·사망 0, 입원·후유장해 30, 암 진단 100)

**문구 규칙 (전 항목 통일)**:
| 금지 | 사용 |
|---|---|
| "내 없음 · 또래 평균 500만" | **"내 보장 없음 · 또래 평균 500만원"** (금액은 항상 "만원") |
| "내 3,000만" | "내 보장 3,000만원" |
| "또래 78%가 가입" | "또래 가입률 78%" |
| (입원) "내 입원일당 1만원" | "내 보장 1만원" (일당 설명은 아래 설명 문장에) |
- 헤드라인은 반드시 2줄 위계(수치 18/700 + 설명 14/400), 한 줄에 합치지 않는다
- 면책: "가입을 권하는 것이 아니에요. 수치는 가상값이에요." (S1과 동일 문구)
