- Figma: 접힘 `485:2920` / 펼침 `S3-C-1` `604:8662`

**티어 전체 매핑 (2026-08-26 확정 — 이걸로 데이터 모델에 `tier` 필드 추가)**:

티어는 기존 `group`(치료비/큰 병/노후·간병/만일)과 **별개 축**이다 — 기준은 "20대 중요도 × 충족 여부"이지 보장 유무가 아니다.

| tier 키 (제안) | 이름 | 항목 (표시 순서 고정) | 카운트 라벨 |
|---|---|---|---|
| `now` | 지금 채우면 좋아요 | 실손의료비 · 입원 — 둘 다 "먼저 볼 항목" 뱃지 | "20대 우선 · 2개 항목" |
| `later` | 여유 있을 때 봐도 돼요 | 수술 · 치과치료 · 심혈관질환진단 · 뇌혈관질환진단 · 치매진단 · 후유장해 | "6개 항목" |
| `covered` | 이미 준비돼 있어요 | 암 진단 | "1개 항목" |
| `notyet` | 지금은 서두르지 않아도 돼요 | 사망 | "1개 항목" |

- **후유장해가 `later`인 것은 의도** — 보유(1,000만) 중이지만 또래 수준(3,000만) 미달이라 `covered` 자격이 없고, 20대 중요도가 낮아 `now`도 아니다. 반례로 입원은 일부 보유인데도 중요도가 높아 `now`. `covered`는 "또래 평균 도달"만 들어간다.
- 접기 규칙: 티어당 앞 3개 표시, 나머지 접힘 — 별도 선정 기준 없음, **티어 내 고정 순서** 필드로 구현
- 카운트 라벨은 티어별 문자열이 다름(`now`만 "20대 우선 ·" 접두) — 데이터에 라벨 통째로 두는 게 안전
- 원본 기록: 디자인 레포 `02_to-be/mock-data.md` §2-3
- 항목 배터리 단계 규칙: **없음 = 0 / 일부 보유 = 30 / 또래 평균 도달 = 100** (60은 현재 미사용 — 실손·수술·치과·심혈관·뇌혈관·치매·사망 0, 입원·후유장해 30, 암 진단 100)
