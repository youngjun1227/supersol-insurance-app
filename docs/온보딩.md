## 1. 클론 + 훅 설정 (한 번만)

```bash
git clone https://github.com/youngjun1227/supersol-insurance-app
cd supersol-insurance-app

git config core.hooksPath .githooks   # ⚠️ 절대 빼먹지 마세요

```

### `core.hooksPath` 를 왜 꼭 해야 하나

이 한 줄을 안 하면 **커밋 검사가 하나도 안 걸립니다.** 토큰 이탈·목데이터 오류·`main` 직접 push 가 전부 통과해버리고, 나중에 CI 에서 한꺼번에 막혀 되돌리는 수고가 듭니다.

확인:
```bash
git config core.hooksPath    # → .githooks 가 나와야 정상
```


## 7. PR 올리기

```bash
git push -u origin feat/s1-main
gh pr create            # 또는 GitHub 웹에서
```

PR 템플릿이 자동으로 뜹니다. **figma-ref 비교 스크린샷이 필수**입니다 — 레퍼런스 PNG 와 구현 화면을 나란히 놓고 찍어서 붙이세요. 이게 시각 검수의 유일한 관문입니다.

그다음: **CI 통과 + 팀장 승인 1개** → 팀장이 머지합니다.

### PR에 "out-of-date" 가 뜨면

> This branch is out-of-date with the base branch

다른 사람 작업이 먼저 머지된 겁니다. **충돌이 아니어도 뜹니다** — `main` 이 앞서면 머지 전에 최신화해야 하는 규칙(`strict`)이 걸려 있어서요.

**충돌이 없으면** PR 화면의 **`Update branch`** 버튼 하나로 끝납니다.

**충돌이 있으면** 로컬에서 해결하세요:

```bash
git switch feat/내브랜치
git fetch origin
git merge origin/main
# 충돌난 파일을 열어 해결 → git add → git commit
git push
```

세 사람이 같이 하면 자주 뜹니다. 특히 `src/data/mock.ts` 와 `src/components/index.ts` 는
여러 사람이 건드리는 파일이라 충돌 가능성이 높습니다.

> 💡 최신화하면 CI 가 **합쳐진 상태로** 다시 돕니다. 각자 브랜치에서는 통과했는데
> 합치면 깨지는 문제(예: 목데이터 개수)를 여기서 잡습니다.

## 자주 막히는 곳

| 증상 | 원인·해결 |
|---|---|
| 커밋이 거부된다 | 토큰·목데이터 검사에 걸린 것. 메시지에 어느 줄인지 나옵니다 |
| `main` push 가 거부된다 | 정상입니다. 브랜치를 파세요 |
| force push 가 거부된다 | 정상입니다. **되돌릴 게 있으면 `git revert` 로 새 커밋을 쌓으세요.** 히스토리를 다시 쓰면 남의 커밋이 사라집니다 |
| PR 에 out-of-date 가 뜬다 | 다른 사람 작업이 먼저 머지된 것. `Update branch` (위 절 참고) |
| 윈도우에서 검사가 이상하게 실패한다 | 경로 구분자(`\` vs `/`) 문제일 수 있습니다. **팀장에게 알려주세요** — 맥/리눅스에서는 안 드러나는 종류라 리포트가 없으면 모릅니다 |
| 훅이 아무것도 안 한다 | `git config core.hooksPath .githooks` 를 안 한 것 |
| 폰에서 접속이 안 된다 | 같은 와이파이인지 확인. 회사/학교 망은 기기 간 통신이 막혀 있을 수 있습니다 |
| Figma 값이 토큰에 없다 | 가장 가까운 토큰으로 스냅하고 `docs/디자인변경로그.md` 에 한 줄 남기세요 |
| 목데이터에 필요한 값이 없다 | **지어내지 마세요.** 팀장에게 요청 |
| 공용 컴포넌트가 없다 | **직접 만들지 마세요.** 팀장에게 요청 (각자 만들면 크기·비율이 갈립니다) |

---

## 기억할 것 세 가지

1. **새로 디자인하지 않습니다** — Figma 에 있는 걸 코드로 옮기는 일입니다
2. **지어내지 않습니다** — 목데이터·문구·컴포넌트 전부. 없으면 요청
3. **탭 가능한 모든 요소에 계측** — 9/11 테스트가 이 프로젝트의 존재 이유입니다
